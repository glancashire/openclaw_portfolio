# Phase 202 — Cash Currency Sanity Check

## Objective
The proposal generator currently treats `cashChf` as a single CHF figure. In reality, IBKR holds cash in many currencies and converts as needed. Today we noticed a few EUR.CHF FX executions among the basket fills (orders 9130/9131 with `BOT 3 EUR.CHF @ 0.91405`) that were auto-generated by IBKR to fund the EUR-denominated EMUAA/SXR8 buys. This is mostly fine, but it means our "cash CHF" headline may be optimistic when most of the basket is non-CHF.

Add a lightweight sanity check at proposal time:
- Total proposed deployment per native currency.
- Compare against IBKR's raw `cashDetail` ledger by currency (which `holdingsSnapshot` already pulls).
- Warn (don't block) if any non-CHF leg exceeds available native-currency cash by a margin (configurable, default 50% — we tolerate FX conversion but not arbitrary balance growth).

## Risks / dependencies
- `holdingsSnapshot.js` may not currently expose per-currency cash; check first.
- The IBKR adapter exposes `cashDetail` with tags like `AvailableFunds`, `BuyingPower`, etc. — not always per-currency. Need to look at what the python `account-summary` returns.
- This is a soft warning, not a hard gate; operators may approve overspend in one currency intentionally (IBKR will FX-convert).

## Actionable checklist
- [ ] Inspect `src/brokers/shared/holdingsSnapshot.js` for what cash data shape is exposed.
- [ ] Add a `cashByCurrency` field to the holdings snapshot if not already present.
- [ ] Add a `cashSanity` evaluator to `basketProposalGenerator.js`:
  - Sum legs by currency × limitPrice × qty.
  - Compare against `cashByCurrency`.
  - Return `{ healthy, warnings: [...] }` with per-currency overage detail.
- [ ] Surface in proposal envelope as `cashSanity`.
- [ ] CLI prints a warning line if any currency is over-deployed.
- [ ] Tests:
  - cashSanity returns healthy when within budget.
  - cashSanity returns warning when over budget by ≥ 50%.
  - propose-basket envelope carries `cashSanity` field.

## Acceptance criteria
- Proposal envelope has `cashSanity: { healthy, warnings }`.
- Tests pass.
- All 24 existing focused tests stay green.
