# Template Reports

Use this folder as the copy-safe report skeleton for new portfolios.

Expected output filenames:
- `portfolio_report_<portfolio_name>_weekly_<YYYYMMDD>.md`
- `portfolio_report_<portfolio_name>_weekly_<YYYYMMDD>.pdf`
- `portfolio_report_<portfolio_name>_monthly_<YYYYMMDD>.md`
- `portfolio_report_<portfolio_name>_monthly_<YYYYMMDD>.pdf`
- `portfolio_report_<portfolio_name>_quarterly_<YYYYMMDD>.md`
- `portfolio_report_<portfolio_name>_quarterly_<YYYYMMDD>.pdf`
